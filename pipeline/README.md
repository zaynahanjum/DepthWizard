# Terrain Processing Pipeline

## 1. Overview

The terrain processing pipeline is responsible for preparing Digital Terrain Model (DTM) data for the DepthWizard project.

It takes:
- A georeferenced satellite image (GeoTIFF).
- A corresponding Digital Terrain Model (DTM).

It processes the DTM so that it matches the satellite image's coordinate reference system, spatial resolution, dimensions, and pixel alignment.

The resulting terrain raster can later be integrated with the object information generated by Part A.

## 2. Pipeline Files

| File | Purpose |
|---|---|
| `__init__.py` | Marks the pipeline directory as a Python package, allowing its modules to be imported. |
| `inspect.py` | Inspects the satellite image and DTM, including their dimensions, CRS, bounds, resolution, and raster metadata. |
| `check_location.py` | Converts the satellite image's geographic bounds into latitude and longitude coordinates. |
| `check_dtm.py` | Examines the downloaded DTM, including its CRS, dimensions, resolution, NoData values, and elevation statistics. |
| `terrain.py` | Reprojects and resamples the original DTM to match the satellite image's spatial grid, then saves the aligned terrain raster. |
| `validate_terrain.py` | Checks whether the generated terrain raster matches the satellite image's CRS, dimensions, transform, bounds, and resolution. |
| `visualize_terrain.py` | Displays the satellite image and aligned terrain elevation raster for visual inspection. |

## 3. Processing Workflow

1. Inspect the satellite image and original DTM.
2. Identify the satellite image's geographic coverage.
3. Examine the original DTM metadata and elevation values.
4. Reproject the DTM into the satellite image's coordinate reference system.
5. Resample the DTM using bilinear interpolation.
6. Align the DTM to the satellite image's exact raster grid.
7. Save the aligned terrain raster.
8. Validate the spatial alignment.
9. Visualize the satellite image and terrain elevation data.

## 4. Input Data

Current sample files:

| File | Description |
|---|---|
| `data/samples/satellite.tif` | Georeferenced RGB satellite image. |
| `data/samples/original_dtm.tif` | Original downloaded Digital Terrain Model. |

## 5. Output Data

| File | Description |
|---|---|
| `outputs/terrain_dem.tif` | Reprojected and resampled terrain elevation raster aligned with the satellite image. |

The output raster retains the satellite image's:
- Coordinate Reference System (CRS).
- Width and height.
- Spatial transform.
- Geographic bounds.
- Pixel resolution.

**Note:** Resampling the approximately 30 m source DTM onto a 10 m grid does not create new 10 m terrain detail.

## 7. Running the Scripts

Run commands from the root `DepthWizard` directory with the `depthwizard` Conda environment activated.

Inspect the satellite image and DTM:

```bash
python -m pipeline.inspect
```

Check geographic bounds:

```bash
python -m pipeline.check_location
```

Inspect the original DTM:

```bash
python -m pipeline.check_dtm
```

Generate the aligned terrain raster:

```bash
python -m pipeline.terrain
```

Validate the output:

```bash
python -m pipeline.validate_terrain
```

Visualize the satellite image and terrain:

```bash
python -m pipeline.visualize_terrain
```

## 8. Future Integration

The aligned terrain raster will eventually be combined with the object information produced by Part A.

The intended integration is:

**Object top elevation = Ground elevation + Object height above ground**

The resulting terrain and object data will be used in the 3D visualization stage of DepthWizard.
